## 조사·운영 증거와 공개 배포

4개 지역 조사 JSON은 공식 기관·홈페이지·robots·피드 서비스 페이지의 선언 및 확인 한계를 담는다. 선언 기록은 총 202개 후보 등장 항목이며 중복/언어/섹션 후보를 포함한다. 모두 검증하거나 등록한 주소 수가 아니다. 추가 전 Oracle의 두 제한된 검증은 24개+57개 선정 매체에 대해 실제 HTTP 홉 73+127개를 사용했다. 첫 그룹은 12초, 둘째 그룹은 운영과 같은 8초 제한이었다. 둘째 검증은 리다이렉트의 각 목적지 robots를 요청 전에 확인했다. 등록 후 첫 수집은 실제 운영 8초 제한·병렬 6개·호스트 간격 2초·기존 재시도/429 대기 정책을 사용했고 실제 HTTP 홉은 25개다. 이 숫자에 지역 조사자의 공식 페이지 조회는 포함되지 않는다.

실제 적용 직전 기존 원장과 동일함을 재확인한 당일의 정상 SQLite 백업을 보존했다. 원장의 기존 **58,803개 검사, 2,265,156개 URL의 정체성·최초 발견 시점, 5,861개 바인딩의 9개 필드, 기존 기준선과 추적 시작 시각**은 유지됐다. 검사 22개와 바인딩 22개만 추가했으며 최종 검사 기록은 58,825개, URL 2,270,471개, 바인딩 5,883개다. 기존 모든 소스 메타데이터와 기존 건강 관측·전체 감사, 타이머 파일 해시는 그대로다. 기준선 검증과 원장 비교는 읽기 전용으로 수행했고 전체 수집을 다시 시작하지 않았다.

배포는 현재 설치된 `news-quality-source-pagination-20261014` 코드에서 새 메타데이터와 완전한 체크섬 검증 이력만 준비했다. 최신 로컬의 미배포 모델 조사 수정은 포함하지 않았다. 공개 Vercel 배포 `dpl_HD2bHEpVwD6Cr4nU1Q42uKpHzPjU`의 READY 및 기존 도메인 연결을 API로 확인했다. 정상 인증 게이트웨이·영어 기본/한국어 선택·10/20/50개 페이지네이션을 유지했다. [공개 대시보드](https://news.bymyleslee.com/quality/)에 새 등록과 실제 수집 결과를 반영했다. 배포 URL을 직접 조회한 검증은 하지 않았으며 고정된 업로드 파일 해시·배포 READY/별칭·실제 백엔드 메타데이터 검증을 근거로 삼았다.

전체 로컬 테스트 **360/360개 통과**. 현재 운영 앱의 기존 조사 4개, 비용 예약 323개 및 합산 추정 **$0.076268448/$5**는 그대로이고 이번 보강의 모델 호출은 0이다. 비공개 SQLite·키·HTML/XML 본문은 저장소나 Vercel에 올리지 않았다. 공개 증거 파일에는 집계·정책·공식 선언·검증 관측만 포함했다.

기존 매일 검사 타이머는 그대로이며 추가 주소도 다음 정기 검사 대상이다. 다음 예정은 **2026-10-15 03:00 UTC, 시카고 시간 10월 14일 22:00 CDT**이다. 이번 첫 검사 성공은 다음 정기 회차의 완료나 장기 이상감지 정확도를 증명하지 않는다. 다음 회차에서 비기준선 새 URL과 국가별 완료·유예를 확인해야 한다. 비공개 상세 실행·검증 자료는 `output/news-quality/major-publisher-fill-20261014`에 보존했다.
