## 기록 보존·배포 검증

실제 변경 직전에 동일한 원장과 대조한 **5,325,144,064바이트의 새 일관된 SQLite 백업**을 만들고 `quick_check`를 확인했다. 기존 **58,825개 수집 기록, 2,270,471개 URL 정체성·최초 발견 시각, 5,883개 바인딩의 9개 필드, 모든 기존 기준선·등록 메타데이터·건강 관측·전체 감사·타이머 파일 해시**는 보존했다. 검사와 바인딩이 각각 17개 추가돼 최종 수집 기록 58,842개, URL 2,275,159개, 바인딩 5,900개가 됐다. 추적 시작은 `2026-10-01T01:36:12.370Z` 그대로다. 실제 원장 비교와 [운영 증거](operation-evidence.json)를 남겼으며 전체 활성 수집이나 정기 타이머를 새로 시작하지 않았다.

제한된 사전 검증은 실제 Oracle HTTP 홉 172개, 호스트 간격 2초, 6개 병렬 처리, 8초 요청 제한, 리다이렉트 목적지별 사전 robots 검사로 수행했다. 일부 공식 안내 조회는 웹 검색을 사용했으며 172개에 검색 도구의 트래픽은 포함하지 않았다. 설치된 코드·운영 제한을 바꾸지 않고 선언 및 검증 자료만 비공개 파일로 기록했다. 기사 본문은 요청하지 않았다.

공개 배포 `dpl_2v9WvsN5WJP6hBAgLjo4qY5a8Frn`의 READY 및 기존 도메인 연결을 Vercel API로 확인했다. [공개 대시보드](https://news.bymyleslee.com/quality/)와 MCP 메타데이터에 새 등록을 반영했다. 고정된 공개 업로드 파일의 해시·완전한 체크섬 검증 이력·실제 백엔드의 GET 조회도 대조했다. 배포 URL을 직접 조회한 검증은 하지 않았다. 기존 운영 코드에서 메타데이터만 준비했으며 로컬 모델 조사 수정은 계속 미배포 상태다. 정상 인증 게이트웨이와 품질 앱을 유지했고 웹 서비스 재시작은 수행하지 않았다.
